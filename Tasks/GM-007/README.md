**명세 결함을 테스트로 고정해 두었다.**

- `명세결함_가로베기가_일반공격보다_항상_낫다`: 가로 베기(50)에 비용·쿨타임이 없어서 일반 공격(10)을 고를 이유가 없다.

## 01 턴제 미니 RPG

- 체력: 플레이어 **100**, 몬스터 **200**
- 플레이어 스킬 (배열):

  | 번호 | 스킬 | 효과 |
  |---|---|---|
  | 0 | 일반 공격 | 10 데미지 |
  | 1 | 가로 베기 | 50 데미지 |
  | 2 | 회복 *(직접 지정)* | 체력 +30, 최대 100 |
  | 3 | 방어 *(직접 지정)* | 그 턴 몬스터 공격 절반 |

- 몬스터 스킬 (배열): `0` 일반 공격 10 / `1` 기 모으기
  - 기 모으기를 쓴 턴에는 데미지가 없고, 다음 일반 공격이 x1.5가 된다. 연속으로 쓸 수 없어서 기를 모은 다음 턴에는 반드시 일반 공격을 한다.
  - 일반 공격은 **20%** 확률로 치명타(x2)가 난다.
  - 기를 모은 상태가 아니면 두 스킬 중 무작위로 고른다.
- 플레이어 체력이 0이 되면 `YOU DIED` 문구를 출력하고 종료한다.
- 치트: 스킬 입력 칸에 `c`를 넣으면 메뉴가 열린다. 치트는 턴을 소모하지 않는다.
  - `1` 무적: 켜기/끄기. 켜져 있으면 몬스터 공격 데미지가 0이다.
  - `2` 즉사: 대상을 `1` 몬스터 / `2` 플레이어 중에서 고른다.
- `q`를 넣으면 중단한다.

**명세에 없어서 정한 것**

| 항목 | 정한 내용 |
|---|---|
| 턴 순서 | 플레이어가 먼저, 다음에 몬스터 |
| 스킬 2, 3 | 회복(+30)과 방어(절반). 명세가 "직접 지정"으로 맡김 |
| 몬스터 사망 | 승리 문구 후 종료. 명세에는 플레이어 사망만 있지만, 즉사 치트가 성립하려면 필요함 |
| 기 모음 + 치명타 | 곱해서 10 x1.5 x2 = **30** |
| 치명타 확률 | 20% (명세상 자유) |
| 무작위 패턴 | 기를 모은 상태가 아니면 50:50 |
| 소수점 | 버림 (현재 배율 조합에서는 소수점이 생기지 않음) |
| 치트 여는 방법 · 대상 | `c` → `1` 무적 켜기/끄기, `2` 즉사 → 대상 선택. 치트 번호 1·2가 스킬 번호 0~3과 겹쳐서 메뉴를 따로 둠 |
| 무적 중 플레이어 즉사 | 적용됨 (즉사가 무적보다 우선) |

**구현**

- 스킬은 명세대로 이름·위력 배열로 두고, 효과는 `switch`로 나눈다.
- 몬스터 행동 결과는 `MonsterTurn` 구조체에 담는다. 기 모음·치명타·방어·무적 여부를 함께 담아서 출력할 때 어떤 배율이 붙었는지 태그로 보여준다.
- 무작위(행동 선택·치명타)는 `Random`을 밖에서 받아서, 시드를 고정하면 결과를 재현할 수 있다.
