# GM-023

Unity 과제: 패턴 기억 게임 — 큐브 1개가 4색(빨강 · 초록 · 파랑 · 노랑, 중복 없음) 패턴을 색당 1.5 / 1.0 / 0.5초(라운드별) 보여 주면, 1~4번 키로 같은 순서를 입력한다. 틀리면 빨강 고정, 다 맞히면 초록 고정. 총 3라운드, 끝나면 재시작 / 종료.

| 폴더 | 내용 | 상태 |
|---|---|---|
| [01-pattern](01-pattern) | `PatternGame.cs`: 패턴 생성 · 타이머 표시 · 입력 판정 · 라운드 / 재시작 | 완료 |

## 열기 · 실행

Unity `6000.3.9f1`. GM-022 프로젝트(Universal 3D 템플릿, Active Input Handling `Both`)를 복사해 스크립트와 씬 오브젝트만 바꿨다.

1. Unity Hub → **Add project from disk** → `01-pattern` 선택
2. `Assets/Scenes/SampleScene` 열기 (큐브 `PatternCube`에 `PatternGame` 연결됨)
3. Play → Game 뷰를 클릭해 포커스 → 큐브 색 순서를 본 뒤 회색이 되면 입력

| 키 | 동작 |
|---|---|
| 1 / 2 / 3 / 4 | 빨강 / 초록 / 파랑 / 노랑 입력 (입력 대기 중에만) |
| Space | 라운드 성공(초록) 뒤 다음 라운드 |
| R | 실패(빨강) 또는 3라운드 모두 성공 뒤 1라운드부터 다시 |
| Esc | 실패 또는 3라운드 모두 성공 뒤 게임 종료 (에디터에선 Play 중지) |

진행 안내(라운드 시작 · 입력 시작 · 성공 · 실패)는 Console 로그로 나온다.

## 확인 로그

Unity 과제라 단위 테스트는 붙이지 않았다. Unity 배치 모드에서 임시 에디터 스크립트로 씬을 구성하고, `Step(dt, 키)`를 고정 dt로 반복 호출해 상태 · 맞힌 수 · 큐브 색을 파일로 남겼다. 무작위는 `Random.InitState(seed)`로 고정했다. 임시 스크립트는 커밋하지 않았다.

## 01 패턴

### `PatternGame.cs`

- 상태 `GameState`: `Showing`(패턴 표시) → `Input`(입력 대기) → `RoundClear`(초록) / `Failed`(빨강) / `AllClear`(3라운드 성공, 초록)
- `Update()` → `Step(Time.deltaTime, ReadKey())`. 코루틴 없이 `showTimer += dt`로 표시 시간을 잰다.
- `Showing`: 입력은 보지 않고 `showTimer`가 `showTimePerRound[round - 1]`을 넘으면 다음 색으로(넘은 만큼은 다음 색으로 이월), 4색이 끝나면 회색 + `Input`
- `Input`: 1~4 → 큐브를 그 색으로 → 패턴과 비교. 틀리면 빨강 `Failed`, 4개 다 맞으면 초록 `RoundClear`(3라운드면 `AllClear`)
- `RoundClear`: Space → 다음 라운드 / `Failed` · `AllClear`: R → 1라운드부터, Esc → 종료
- 패턴: `[0,1,2,3]`을 `Random.Range`로 Fisher-Yates 셔플 → 4색 중복 없음, 라운드마다 새로 생성

**명세에 없거나 해석해서 정한 것**

| 항목 | 정한 내용 |
|---|---|
| 성공 후 "다음 라운드" ↔ "재시작 되기 전까지 초록 고정" | 두 문장이 겹친다 → **초록으로 멈춰 있다가 Space를 누르면 다음 라운드** (다음 라운드 시작 = 고정 해제) |
| 틀린 뒤 | "해당 라운드 종료"만 있고 다음 라운드로 가는지 없다 → 성공일 때만 "다음 라운드"라고 했으므로 **실패 = 게임 끝**, R 재시작 / Esc 종료 |
| 재시작 · 종료 키 | 정의 없음 → R / Esc. 실패 또는 3라운드 성공 뒤에만 받는다 |
| 패턴 표시가 끝난 뒤 큐브 색 | 정의 없음 → 회색(입력 대기 표시). 마지막 패턴 색이 남아 있으면 표시가 끝났는지 알 수 없다 |
| 틀린 키의 색 | "입력할 때마다 해당 색"과 "틀리면 빨강 고정"이 같은 순간 → 같은 프레임에 빨강으로 덮는다 (틀린 색은 안 보임) |
| 마지막 정답 키의 색 | 같은 이유로 같은 프레임에 초록으로 덮인다 (명세대로 두고 리뷰에 적음) |
| 패턴 | "4단계" + "4색 중복 없음" → 4색을 한 번씩 쓰는 순서(24가지). 라운드마다 새로 뽑는다 |
| 색 사이 간격 | 정의 없음 → 간격 없이 바로 다음 색 (중복이 없어 이어지는 같은 색은 생기지 않는다) |
