## 01 숫자 야구

0~9 중 컴퓨터가 뽑은 숫자 3개를 숫자와 자리까지 맞추는 게임이다.

- 판정은 자리마다 한다. 숫자와 자리가 같으면 **S**, 숫자만 있으면 **B**, 없으면 **O**이다. 결과는 `1S 1B 1O`처럼 표시한다.
- 3S가 나오면 `N번 만에 맞췄습니다.`를 출력하고, 재시작(`y`)과 종료(`n`) 중 하나를 고른다.
- 치트: 입력 칸에 `c`를 넣으면 **그 판의 정답이 `3 6 9`로 바뀌고** `컴퓨터가 갖고 있는 숫자 : 3 6 9`가 출력된다.
- `q`를 넣으면 중단한다.

**명세에 없어서 정한 것**

| 항목 | 정한 내용 | 이유 |
|---|---|---|
| 컴퓨터 숫자 중복 | 중복 없이 뽑음 | 치트 예시 `3 6 9`가 모두 다른 숫자 |
| 플레이어 입력 중복 | 거부하고 다시 입력 | 허용하면 `3 3 3` → 1S 2B (위 테스트) |
| 입력 형식 | `1 2 3`, `123` 둘 다 허용 | 명세에 형식이 없음 |
| 무효 입력 | 안내만 하고 시도 횟수에 넣지 않음 | "몇 번 만에"를 셀 때 오타까지 세지 않도록 |
| 시도 횟수 상한 | 없음 | 명세에 없음 |
| 치트를 켜는 방법 | 입력 칸에 `c` | 명세에 없음 |
| 게임 도중 치트 | 정답만 바꾸고 **앞선 시도 횟수는 유지** | 명세에 없음 (`run-03` 참고) |
| "프로그램 종료" 후 재시작 선택 | 게임만 끝내고 재시작 여부를 물음 | 원문의 두 문장이 서로 충돌함 |

**구현**

- 숫자 생성: `0~9` 배열의 앞 3칸만 Fisher-Yates로 섞는다. 중복이 생기지 않아서 다시 뽑는 루프가 필요 없다.
- 판정: 자리마다 `같은 자리 일치 → S`, `정답에 있음 → B`, `없음 → O`의 `if` 체인을 적용한다. 명세 문장을 그대로 옮겼다.
- 재시작 입력은 `switch`로 `y` / `n` / 그 밖의 입력을 나눈다.
- 실행 인자로 시드를 넘기면 결과를 재현할 수 있다. 예: `dotnet run -- 1` (정답 `2 1 5`)
