# GM-012

C# 콘솔 과제: 게임 데이터베이스 흉내 내기 (클래스 없이 구조체 · enum · 튜플 · 구조체 배열 · 조건 선별).

| 폴더 | 내용 | 상태 |
|---|---|---|
| [01-game-database](01-game-database) | 게임 5개를 구조체 배열에 넣고, 메뉴로 전체 출력 / 조건 출력(평점 9.0 이상 · Adult · 특이사항 있음) / 종료 | 완료 |

## 빌드 · 실행

.NET 9 SDK와 Visual Studio 2022를 쓴다. `GM-012.sln`을 VS에서 열면 된다.

```powershell
dotnet build GM-012.sln
dotnet run --project 01-game-database
```

## 테스트

구조체와 선별 작업은 `Game.cs`에 두고, `Program.cs`는 메뉴 입출력만 맡는다.

```powershell
dotnet test GM-012.sln
```

## 01 게임 데이터베이스

메뉴는 다음 순서로 진행된다.

1. **메인 메뉴**: `1. 모든 게임 정보 출력` / `2. 특정 조건의 게임 출력` / `3. 종료`. `3`을 고를 때까지 반복한다.
2. **전체 출력**: `for` 반복문으로 5개 게임의 타이틀 · 이용 등급 · 가격 · 평점 · 특이사항을 출력한다.
3. **조건 출력**: `1. 평점 9.0 이상` / `2. Adult 등급` / `3. 특이사항이 있는 게임` 중 하나를 고르면 선별한 결과를 출력하고 메인 메뉴로 돌아간다.
4. 메뉴 · 조건에서 `1`~`3` 외의 입력은 다시 받는다.

**명세에 없거나 해석해서 정한 것**

| 항목 | 정한 내용 |
|---|---|
| "클래스 x" | `class`를 직접 쓰지 않는다. `class Program` 대신 최상위 문(top-level statements)으로 시작하고, 데이터 · 선별 함수는 구조체 `Game` · `GameDb`에 둔다 (컴파일러는 최상위 문을 숨은 Program 클래스로 만든다) |
| 특이사항 튜플 모양 | `(bool DlcSoon, bool BadOptimization, bool ManyBugs)` — 세 항목 각각 해당 여부. 여러 개가 동시에 해당할 수 있음 |
| 평점 만점 | 10점 만점 (예시 조건 "9.0 이상"에 맞춤) |
| 가격 단위 | 원 (`int`), 천 단위 쉼표 |
| 조건 출력 | 예시 세 가지를 그대로 구현. 조건 출력 후 메인 메뉴로 돌아감 |
| 메뉴 반복 | 한 번 출력하고 끝내지 않고 `3. 종료`까지 반복 |
| 게임 선정 | 엘든 링 · 스타듀 밸리 · 몬스터 헌터 와일즈 · 사이버펑크 2077 · 팰월드. 평점 · 특이사항은 조건 출력이 골고루 확인되도록 정한 **예시 값**이다 (실제 평가 자료가 아님) |

**구현**

- `AgeRating` enum, `Game` 구조체(타이틀 · 등급 · 가격 · 평점 · 특이사항 튜플), 게임 배열을 담는 `GameDb` 구조체.
- 선별 작업은 `ScoreAtLeast` · `WithRating` · `WithAnyNote`가 `foreach` + `if`로 맞는 게임만 모아 새 배열로 돌려준다. 원본 배열은 바꾸지 않는다.
- 실행 로그는 `01-game-database/screenshots/`에 있다.

| 파일 | 내용 |
|---|---|
| `run-01-all.txt` | 1 → 5개 전체 출력 → 3 종료 |
| `run-02-high-score.txt` | 2 → 1 평점 9.0 이상 (엘든 링 9.5 · 스타듀 밸리 9.0 경계) |
| `run-03-adult.txt` | 2 → 2 Adult (엘든 링 · 사이버펑크 2077) |
| `run-04-notes.txt` | 2 → 3 특이사항 있음 (3개, 두 개가 겹치는 게임 포함) |
| `run-05-invalid.txt` | 메뉴 `4` · `abc` · 빈 값, 조건 `9` · `x` 거부 |
