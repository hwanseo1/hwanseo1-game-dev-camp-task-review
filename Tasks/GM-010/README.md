| 폴더 | 내용 | 상태 |
|---|---|---|
| [01-strings](01-strings) | `switch` 메뉴로 거꾸로 · 짝수 번째만 거꾸로 · 숫자만 · 문자 개수 · 주민번호 `-` 제거 | 완료 |

## 빌드 · 실행

.NET 9 SDK + Visual Studio 2022. `GM-010.sln`을 VS에서 열면 된다.

```powershell
dotnet build GM-010.sln
dotnet run --project 01-strings
```

## 테스트

기능 5개는 `StringRules.cs`에 따로 두고, `Program.cs`는 메뉴와 입출력만 맡는다.

```powershell
dotnet test GM-010.sln
```

**27개 전부 통과**. 결과는 `screenshots/dotnet-test.txt`에 있다.

| 대상 | 확인 내용 |
|---|---|
| 거꾸로 | `ABCD → DCBA`, 한 글자 · 빈 문자열 · 한글 · 공백 포함 |
| 짝수 번째만 거꾸로 | `ASDF → AFDS`, 홀수 길이 `ABCDE → ADCBE`, `ABCDEF → AFCDEB`, 짝수 번째가 하나뿐인 경우 |
| 숫자만 | `A1B2C3 → 123`, 숫자 없음 → 빈 결과, 전각 `１２`는 제외 |
| 문자 개수 | `ABCDAA` 중 `A` → 3, 대소문자 구분, 공백도 셈 |
| 주민번호 | `-` 위치 · 개수와 상관없이 제거 |

**명세 결함을 테스트로 고정해 두었다.**

- `명세결함_짝수를_0부터_세면_예시와_다르다`: "짝수"가 몇 번째부터 세는지 문장에 없다. 0부터 세면 `ASDF → DSAF`. 예시 `AFDS`는 1부터 셀 때만 맞는다.
- `명세결함_예시는_하이픈만이_아니라_공백도_지운다`: 문장은 "`-` 제거"인데 예시 `1234567 - 12345678 → 123456712345678`은 공백도 지운다. 예시에 맞췄다.
- `명세결함_예시_주민번호는_실제_자릿수와_다르다`: 예시는 7자리-8자리(15자리). 실제 주민번호는 6자리-7자리(13자리)다.
- `명세결함_이모지는_char_단위로_뒤집으면_깨진다`: 반복문으로 `char`를 뒤집으면 이모지(서로게이트 쌍)가 깨진다. 과제 범위 밖이라 그대로 두고 기록만 했다.

## 01 문자열 활용

- 시작하면 메뉴 1~5를 보여 주고 `switch`로 고른다. 1~5 외 입력은 다시 받는다.
- 고른 기능을 한 번 실행하고 끝난다.

| 번호 | 기능 | 예시 |
|---|---|---|
| 1 | 거꾸로 출력 | `ABCD → DCBA` |
| 2 | 짝수 번째(1부터 셈) 문자만 거꾸로 | `ASDF → AFDS` |
| 3 | 숫자만 출력 | `A1B2C3 → 123` |
| 4 | 문자열 안의 문자 개수 | `ABCDAA`, `A` → `3` |
| 5 | 주민번호 `-` 제거 | `1234567 - 12345678 → 123456712345678` |

**명세에 없어서 정한 것**

| 항목 | 정한 내용 |
|---|---|
| 몇 번 하나 | 기능 하나를 실행하고 끝남 (반복 · 종료 메뉴는 명세에 없음) |
| 메뉴에서 1~5 외 입력 | 다시 입력받음 |
| 짝수 번째 | 1부터 셈 (예시에 맞춤) |
| 숫자 | `0`~`9`만 |
| 문자 개수 | 대소문자 구분. 문자 입력이 한 글자가 아니면 다시 받음. 공백도 한 글자로 침 |
| 주민번호 | `-`와 공백 제거 (예시에 맞춤). 자릿수 · 형식 검사는 명세에 없어서 하지 않음 |
| 입력 앞뒤 공백 | 자르지 않고 그대로 씀 |

**구현**

- "조건문 + 반복문을 많이 사용"에 맞춰 `Array.Reverse` · LINQ 없이 `for` / `foreach` / `while`로 만들었다.
- 짝수 번째 뒤집기는 양 끝(2번째, 마지막 짝수 번째)에서 두 칸씩 안쪽으로 오며 바꾼다.
- 실행 로그: `01-strings/screenshots/` (기능 1~5, 메뉴 오류 · 문자 두 개 입력 거부 포함).
