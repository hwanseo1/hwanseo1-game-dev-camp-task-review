**명세 결함을 테스트로 고정해 두었다.**

- `명세결함_상시치트와_비용없는_폴드면_같은숫자_판_말고는_돈을_잃지_않는다`: 상시 치트로 가운데 카드가 보이고 폴드에 비용이 없다. 이기는 판만 걸면 시드 1,000개 모두에서 돈이 줄어든 판은 같은 숫자 판(강제 1,000원)뿐이다.
- `명세결함_연속된_숫자는_이길_수_있는_카드가_없다`: `6 / ? / 7`처럼 붙은 숫자는 사이에 들어갈 수가 없다. 같은 숫자처럼 무조건 지는 판인데, 명세는 같은 숫자만 자동 패배로 다룬다.
- `명세결함_소지금이_0원도_아니고_최소배팅도_안_되는_상태가_생긴다`: 배팅 단위가 없어서 9,500원을 걸고 지면 500원이 남는다. 0원이 아니라 끝나지 않는데 최소 배팅 1,000원은 낼 수 없다.

## 01 월남뽕

- 덱: ♠ ♦ ♣ ♥ x 1~13 = **52장**. 시작할 때 한 번 섞는다 (Fisher-Yates).
- 한 판에 3장을 꺼내 `앞 / ? / 뒤`로 놓는다. 출력은 A=1, J=11, Q=12, K=13으로 변환한다.
- 소지금 **10,000원**, 최소 배팅 **1,000원**. 앞뒤 두 장을 보고 배팅한다.
- 가운데 카드 숫자가 두 장 사이(**초과 ~ 미만**)면 **배팅금 x2 획득**, 아니면 배팅금 차감. 문양은 보지 않는다.
- 앞뒤가 **같은 숫자**면 배팅 없이 패배, **1,000원 차감**.
- 배팅 칸에 `fold`를 넣으면 그 판을 끝낸다.
- 쓴 카드는 버린다. 3 x 17 = 51장 → **17판** 후 1장은 버려진다.
- 종료: 소지금 0원 / 17판 완료. `q`로 중단.
- 치트
  - 상시: 매 판 가운데 `?` 카드를 옆에 `[치트] ? = ♦ 7`로 보여준다.
  - `p`: 다음 판의 `?` 카드 1장을 미리 본다. 마지막 판이면 "다음 판 없음".
  - `l`: 아직 나오지 않은 카드 전체(이번 판 3장 제외)를 문양별로 보여준다.
  - 치트 키는 판을 넘기지 않고 다시 배팅을 입력받는다.

**명세에 없어서 정한 것**

| 항목 | 정한 내용 |
|---|---|
| 상시 치트 "컴퓨터가 들고 있는 패" | 월남뽕에는 컴퓨터 상대가 없다. 딜러가 엎어 둔 가운데 `?` 카드로 봤다 |
| 치트 1 "다음 턴 카드 (1장)" | 다음 판의 `?` 카드. 상시 치트(이번 판 `?`)와 짝을 맞춤 |
| 치트 키 | `p` / `l`. 배팅 칸이 숫자를 받기 때문에 키 `1`·`2`를 쓰면 배팅 금액과 겹친다 |
| 치트 2 목록 | 이번 판 3장을 뺀 남은 덱. 덱 순서대로 보여주면 치트 1이 필요 없어져서 문양 → 숫자 순으로 정렬 |
| 세 번째 카드의 위치 | 가운데 `?`. 출력 예시가 `♥ A / ? / ♣ K`라서 "앞쪽 2장"은 실제로는 1번·3번 자리다 |
| "배팅금의 2배를 획득" | 소지금 +배팅금 x2. 배팅금은 미리 떼지 않고, 지면 "배팅한 만큼 차감"과 짝을 맞춤 (GM-005 "x3 획득"과 같은 해석) |
| 큰 수가 앞에 올 때 | 순서 상관없이 두 수 사이로 판정 (`K / ? / 4`에 5면 승리) |
| 배팅 상한 | 소지금까지 |
| 소지금이 1,000원 미만 | 남은 소지금 전액이 최소 배팅. 같은 숫자 판에서는 남은 만큼만 차감 |
| 폴드 비용 | 없음. 소지금 그대로, 카드는 버리고 판 수에 포함 |
| 같은 숫자 판의 폴드 | 불가. "배팅 X → 무조건 패배"라 배팅 입력 자체를 받지 않음 |
| 종료 문구 | 종료 사유와 최종 소지금 출력 |

**구현**

- 카드는 `Card` 구조체(문양 `enum Suit` + 숫자 1~13), 판정 결과는 `enum Result { Win, Lose, Pair }`.
- 출력 변환(`RankText`)과 정산(`Delta`)은 `switch`로 나눈다.
- 덱은 `List<Card>` 하나에 섞어 두고, 판 번호 x 3 위치에서 3장을 꺼낸다. 버린 카드를 따로 지우지 않아도 다시 나오지 않는다.
- 셔플은 `Random`을 밖에서 받아서, 시드를 고정하면 결과를 재현할 수 있다.
