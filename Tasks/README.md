# Tasks

Task 하나당 폴더 하나. Unity 프로젝트는 폴더 안에 그대로 두면 됩니다.

```
Tasks/
└── Task-01-<짧은이름>/
    ├── README.md        # 수행 요약
    ├── Assets/          # Unity 프로젝트
    ├── Packages/
    ├── ProjectSettings/
    └── screenshots/     # 오류 화면 · 결과 화면
```

`Library/`, `Temp/`, `obj/`, `Build/`, `.sln`, `.csproj`는 `.gitignore`로 제외됩니다.
