|---|---|---|
| [01-rrn-generator](01-rrn-generator) | 생년(4자리 · 2자리 선택) · 월 · 일 · 성별 입력 → `YYMMDD-성별+6자리` 생성, 뒤 6자리 재생성 최대 3번 | 완료 |

## 빌드 · 실행

.NET 9 SDK와 Visual Studio 2022를 쓴다. `GM-011.sln`을 VS에서 열면 된다.

```powershell
dotnet build GM-011.sln
dotnet run --project 01-rrn-generator
```

| 대상 | 확인 내용 |
|---|---|
| 생년 | 4자리 · 2자리만 받음, 1 · 3 · 5자리 · 문자 거부, 자동 변환 경계 `24 → 2024` · `25 → 1925` |
| 월 · 일 | `06` · `6` 둘 다 받음, `006` 거부, 월 1~12, 31일 달 7개 · 30일 달 4개 · 2월 |
| 윤년 | 2004 · 2000 윤년, 1900 · 2001 평년, 2월 29일 허용 여부 |
| 성별 | `1`~`4`는 그대로 쓰고, 그 밖의 값(`0` · `5` · `12` · 문자 · 빈 값)은 1~4 중 무작위 (200번 뽑아 네 값이 모두 나오는지 확인) |
| 뒤 6자리 | 10,000번 생성해 0이 없고 같은 숫자가 연속되지 않는지 확인, 1~9가 모두 나오는지, 첫 자리가 성별 숫자와 겹치지 않는지 |
| 출력 | `750606-1234567`처럼 앞자리를 두 자리씩 채움 (`000101`처럼 앞자리의 0은 생년월일이라 허용) |

**명세 결함을 테스트로 고정해 두었다.**

- `명세결함_기준연도가_24로_고정이라_2025년생은_1925년으로_바뀐다`: 2026년에 `25`를 입력하면 자동 변환 결과가 1925가 된다.
- `명세결함_2자리_00은_1900과_2000의_2월_29일_허용이_다르다`: 명세에 윤년이 없다. `00`을 어느 세기로 고르느냐에 따라 2월 29일 허용 여부가 달라진다.
- `명세결함_1975년생에_성별_3을_넣어도_막을_규칙이_없다`: 실제 규칙은 1900년대 1/2, 2000년대 3/4이다. 명세에는 "남자 1 / 3"만 있어서 `750606-3…`도 만들어진다.
- `명세결함_출력_예시_123456은_34월_56일이라_월일_규칙에_어긋난다`: 출력 예시의 앞자리가 명세의 월 · 일 규칙을 어긴다.

## 01 주민등록번호 형식 생성기

입력과 흐름은 다음 순서로 진행된다.

1. **생년**: 4자리를 넣으면 그대로 쓴다. 2자리를 넣으면 `1. 19xx` / `2. 20xx` 중에서 고른다. 자동 변환 규칙(00~24 → 2000년대, 25~99 → 1900년대)에 해당하는 쪽에 `(자동)` 표시가 붙고, Enter를 누르면 그 값으로 정해진다.
2. **월 · 일**: 1자리와 2자리를 모두 받는다. 일은 월에 맞춰 검사한다(31일 · 30일 · 2월은 윤년이면 29, 아니면 28).
3. **성별**: `1`~`4`를 넣으면 그대로 쓰고, 그 밖의 값을 넣으면 1~4 중에서 무작위로 정한 뒤 정해진 값을 알려 준다.
4. **출력**: `YYMMDD-G######` 형식이다. 뒤 6자리는 1~9로만 이루어지고, 같은 숫자가 연속으로 나오지 않는다.
5. **재생성**: `Y`를 누르면 뒤 6자리만 새로 뽑는다. 3번 재생성하면 자동으로 종료하고, `N`을 누르면 바로 종료한다. `Y` · `N` 외의 입력은 다시 받는다.

**명세에 없거나 서로 충돌해서 정한 것**

| 항목 | 정한 내용 |
|---|---|
| 2자리 연도: 자동 변환과 사용자 선택이 함께 있음 | 선택지를 띄우고, 자동 변환 결과를 `(자동)` 표시와 Enter 기본값으로 둠 |
| 4자리 연도 범위 | 제한 없음 (`0000`~`9999`, 명세에 범위가 없음) |
| 2월 | 윤년이면 29일, 아니면 28일 (생년을 이미 알고 있어서 판정 가능) |
| 성별 숫자 | `1`~`4` 직접 입력. 생년과 맞는지(1900년대 1/2 · 2000년대 3/4)는 검사하지 않음 |
| "다른 숫자" | 숫자가 아닌 입력과 빈 값도 무작위로 처리 |
| 0 · 연속 금지 범위 | 뒤 6자리 + 바로 앞 성별 숫자와의 경계 (`1-1…` 방지). 앞 6자리(생년월일)는 0이 들어갈 수 있으므로 제외 |
| 재생성 대상 | 뒤 6자리만. 생년월일과 성별은 처음 입력한 값을 유지 (무작위로 정해진 성별도 유지) |
| 잘못된 입력 | 생년 · 월 · 일 · 선택 · Y/N 모두 다시 입력받음 |

**구현**

- `ResidentNumber` 구조체 하나에 생년 · 월 · 일 · 성별 숫자 · 뒤 6자리를 묶고, `ToString()`으로 `123456-1234567` 형식을 만든다.
- 뒤 6자리는 매 자리를 "1~9 중 바로 앞 숫자를 뺀 8개"에서 한 번에 고른다. 조건에 맞을 때까지 다시 뽑는 반복이 없다.
