# GM-022

Unity 과제: 과열 시스템 — 도형(큐브) 플레이어가 Space를 누르고 있는 동안 히트 증가, 떼면 감소(0~100, `Mathf.Clamp`), 80 이상 과열(입력 무시, 2초 뒤 자동 냉각, 20 이하 해제), 히트에 따라 색(파랑 / 노랑 / 빨강) · 크기 · 흔들림 회전.

| 폴더 | 내용 | 상태 |
|---|---|---|
| [01-overheat](01-overheat) | `OverheatPlayer.cs`: 히트 증감 · 과열 상태 · 색 / 크기 / 회전 연출 | 완료 |

## 열기 · 실행

Unity `6000.3.9f1`. GM-021 프로젝트(Universal 3D 템플릿, Active Input Handling `Both`)를 복사해 스크립트와 씬 오브젝트만 바꿨다.

1. Unity Hub → **Add project from disk** → `01-overheat` 선택
2. `Assets/Scenes/SampleScene` 열기 (큐브 `Player`에 `OverheatPlayer` 연결됨)
3. Play → Game 뷰를 클릭해 포커스 → Space 누르고 있기 / 떼기
4. 수치는 Inspector가 아니라 Console 로그(과열 진입 · 해제)로 나온다. 속도 · 기준값은 Inspector에서 바꿀 수 있다.

## 확인 로그

Unity 과제라 단위 테스트는 붙이지 않았다. Unity 배치 모드에서 임시 에디터 스크립트로 씬을 구성하고, `Step(dt, Space 누름 여부)`를 고정 dt로 반복 호출해 히트 · 상태 · 색 · 크기 · 회전을 파일로 남겼다. 임시 스크립트는 커밋하지 않았다.

| 파일 | 내용 |
|---|---|
| `run-00-scene.txt` | 씬 구성: `Player` 큐브 + `OverheatPlayer`, 설정값 |
| `run-01-hold-release.txt` | 1.25초 누름(0→50, 파랑→노랑, 커짐 · 흔들림) → 뗌(50→0, 작아짐 · 회전 0), 0에서 멈춤 |
| `run-02-hold-through-overheat.txt` | 9초 계속 누름: 2초에 80 과열 → 2초 동안 80 유지(누르고 있어도 증가 x) → 냉각 → 20에서 해제 → 다시 증가 → 재과열 |
| `run-03-overheat-then-release.txt` | 과열 직후 뗌: 떼도 2초 동안 80 유지, 그 뒤 감소, 20에서 해제 |
| `run-04-clamp-colors.txt` | dt를 크게 줘서 200 → 100, -200 → 0으로 잘리는지(`Mathf.Clamp`), 색 경계 39.9 / 40 / 79.9 / 80 |
| `run-05-shake-60fps.txt` | 60fps에서 흔들림 회전 ±8°, 떼는 순간 0° |

※ run-01~03은 dt 0.125(값이 딱 떨어지게)라 흔들림이 표본 추출되어 작게 찍힌다. 실제 프레임(60fps) 회전은 run-05.

## 01 과열

### `OverheatPlayer.cs`

- `Update()` → `Step(Time.deltaTime, Input.GetKey(KeyCode.Space))`
- `Step`:
  - 과열 중: Space 무시, `overheatTimer += dt`, 2초가 지나면 `heat -= coolDownSpeed * dt`
  - 정상: 누르고 있으면 `+= heatUpSpeed * dt`, 떼면 `-= coolDownSpeed * dt`
  - `heat = Mathf.Clamp(heat, 0f, 100f)`
  - 80 이상 → 과열 진입(타이머 0), 과열 중 20 이하 → 해제
  - 이전 값과 비교해 증가 / 감소 / 유지 판단 → 연출
- 연출: 색 `HeatColor(heat)`, 크기 `기본 × (1 + heat/100 × 0.5)`, 증가 중에만 Z축 `sin` 흔들림(±8°)

**명세에 없거나 해석해서 정한 것**

| 항목 | 정한 내용 |
|---|---|
| 증가 · 감소 속도 | 정의 없음 → 증가 40/초(0→80 2초), 감소 30/초 (과열 냉각도 같은 속도) |
| 과열 후 2초 동안 | "Space를 떼면 감소"와 "2초가 지나면 감소 시작"이 겹친다 → **과열 중엔 Space를 떼도 2초 동안 감소하지 않는다** (과열 패널티) |
| 과열 냉각 중 Space | 20 이하로 해제되기 전까지 계속 무시. 해제되는 순간부터 누르고 있으면 바로 다시 증가 |
| 스케일 증가 / 감소 | 얼마나, 상한이 있는지 정의 없음 → 히트에 비례(히트 0 = 1배, 100 = 1.5배). 히트가 오르면 커지고 내리면 작아져 명세를 만족하고 무한히 커지지 않는다 |
| 흔들림 회전 | "살짝 흔들리는 느낌" → Z축 ±8° 사인파, 증가 중에만. 증가가 멈추면(떼기 · 과열 유지) 즉시 0° |
| 색 구간 | 히트가 소수라 `< 40` 파랑, `< 80` 노랑, 그 외 빨강 (39.9는 파랑) |
| 플레이어 도형 | 큐브 (회전이 잘 보이게) |
| 0 / 과열 유지 구간 | 값이 안 바뀌면 "유지" — 흔들림 없음, 크기 그대로 |
