# GM-021

Unity 과제: 3개 스위치 중 정답 스위치 찾기 — 큐브 3개를 스위치로, 라운드마다 `Random.Range`로 정답, `1` / `2` / `3` 선택(맞으면 초록 · 틀리면 빨강), 라운드 시작 시 회색, 선택마다 Scene 뷰 라인(`Debug.DrawLine`), 10라운드 후 정답률, `C` 치트.

| 폴더 | 내용 | 상태 |
|---|---|---|
| [01-switch](01-switch) | `SwitchGame.cs`: 라운드 시작(회색 · 정답 결정) / 선택(색 · 라인 · 판정) / 치트 / 정답률 | 완료 |

## 열기 · 실행

Unity `6000.3.9f1`. GM-018 프로젝트(Universal 3D 템플릿, Active Input Handling `Both`, URP 머티리얼 업그레이드 반영)를 복사해 스크립트와 씬 오브젝트만 바꿨다.

1. Unity Hub → **Add project from disk** → `01-switch` 선택
2. `Assets/Scenes/SampleScene` 열기 (큐브 `Switch1` · `Switch2` · `Switch3`, 빈 오브젝트 `SwitchGame`에 스크립트 · 스위치 3개 연결됨)
3. Play → Game 뷰를 클릭해 포커스 → `1` / `2` / `3` 선택, `C` 치트
4. 라인은 **Scene 뷰**에서 보인다 (Game 뷰에서도 보려면 Gizmos 켜기)

## 확인 로그

Unity 과제라 단위 테스트는 붙이지 않았다. Unity 배치 모드에서 임시 에디터 스크립트로 씬을 구성하고, 키에 해당하는 메서드를 순서대로 호출해 Console 로그와 스위치 색을 파일로 남겼다. 배치 모드에선 `Invoke`가 돌지 않아 다음 라운드는 직접 호출했다. 임시 스크립트는 커밋하지 않았다.

| 파일 | 내용 |
|---|---|
| `run-00-scene.txt` | 씬 구성: 큐브 3개 위치(-2.5 / 0 / 2.5), SwitchGame 연결 |
| `run-01-10rounds.txt` | `Random.InitState(21)`, 매 라운드 C → 1/2/3 순환 선택: 라운드 시작마다 전부 회색, 고른 스위치만 빨강/초록, 라인 끝점, 결과 표시 중 두 번째 키 무시, 정답률 3/10 (30%), 종료 뒤 입력 안내 |
| `run-02-cheat-all-correct.txt` | `Random.InitState(7)`, C로 본 정답만 선택 → 10/10 (100%) |
| `run-03-random-range.txt` | `Random.Range(0, 3)` → 0/1/2 고르게, `Random.Range(1, 3)` → 1/2만 (최댓값 제외) |

## 01 스위치

### `SwitchGame.cs`

- `StartRound()`: 라운드 +1 → 스위치 3개 회색 → `answerIndex = Random.Range(0, switches.Length)` (0~2)
- `Choose(index)`: 정답 비교 → 고른 스위치만 초록/빨강 → `Debug.DrawLine(lineStart, 스위치 위치, 결과 색, resultDelay)` → 10라운드면 정답률 출력 후 종료, 아니면 `Invoke(StartRound, resultDelay)`
- `ShowCheat()`: `[치트] 라운드 N 정답 인덱스: 1 (2번 스위치)`
- 입력은 `Update`의 `Input.GetKeyDown`만 사용 (`Alpha1~3`, `C`)

**명세에 없거나 해석해서 정한 것**

| 항목 | 정한 내용 |
|---|---|
| 다음 라운드 시점 | 정의 없음. 선택 즉시 넘어가면 곧바로 회색으로 초기화되어 초록/빨강이 안 보인다 → **1초(`resultDelay`) 보여 준 뒤** 자동으로 다음 라운드. 그동안 입력 무시 |
| 라운드당 선택 횟수 | "선택할 때마다"는 여러 번처럼 읽히지만 정답률(10라운드 기준)을 위해 **라운드당 1번** |
| 라인 시작점 · 끝점 | 정의 없음 → 스위치 아래 `(0, -2, 0)`(플레이어 자리)에서 고른 스위치까지, 결과 색, 1초 유지 |
| 치트 인덱스 | 원문대로 **인덱스(0~2)** 를 출력하되, 키(1~3)와 어긋나 헷갈리므로 `(2번 스위치)`를 같이 표시 |
| 스위치 도형 | 정의 없음 → 큐브 |
| 정답률 형식 | `3/10 (30%)` |
| 10라운드 이후 | 정의 없음 → 재시작 없이 종료, 선택 키는 "게임이 끝났습니다." · C는 무시 |
| 정답 표시 | 틀렸을 때 정답 스위치 색은 바꾸지 않음 (명세는 "선택한 스위치"만). 로그에 정답 번호만 출력 |
